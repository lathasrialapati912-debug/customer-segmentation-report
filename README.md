# Customer Segmentation Project

## 📌 Project Overview

This project segments customers based on their demographic and purchasing behavior using K-Means clustering.

The goal is to identify groups of customers with similar characteristics and understand their purchasing patterns.

## 🎯 Objectives

- Analyze customer demographics
- Analyze purchasing behavior
- Identify customer groups using clustering
- Visualize customer segments
- Generate useful business insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- K-Means Clustering

## 📊 Dataset Features

The dataset contains the following features:

- CustomerID
- Age
- Gender
- AnnualIncome
- SpendingScore
- PurchaseFrequency
- AveragePurchaseValue
- Recency

## 🔄 Project Workflow

1. Data Collection
2. Data Loading
3. Data Understanding
4. Data Cleaning
5. Exploratory Data Analysis
6. Feature Selection
7. Feature Scaling
8. Elbow Method
9. K-Means Clustering
10. Customer Segment Analysis
11. Visualization
12. Business Insights

## 🤖 Machine Learning Method

K-Means clustering was used to group customers with similar characteristics.

StandardScaler was used before clustering so that features with different numerical ranges could be compared fairly.

## 📈 Visualizations

The project includes visualizations for:

- Customer age distribution
- Annual income distribution
- Spending score distribution
- Income vs spending score
- Purchase frequency vs spending score
- Elbow method
- Customer clusters
- Number of customers in each segment

## 💡 Business Insights

The clusters can help businesses understand differences in:

- Customer spending behavior
- Purchase frequency
- Customer value
- Income levels
- Customer engagement

These insights can support targeted marketing and customer-retention strategies.

## 🏁 Conclusion

Customer segmentation provides a data-driven way to understand different types of customers. K-Means clustering was used to identify groups with similar demographic and purchasing characteristics.

The project demonstrates the use of Python, exploratory data analysis, machine learning, visualization, and business analytics in a customer analytics problem.
